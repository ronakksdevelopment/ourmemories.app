Our Memories

A private gallery just for the two of you, built on your own Google Drive.

1. Connect this app to Google

Paste the Client ID and API key from your Google Cloud project. These stay only in this browser — never in the app's code.

2. Sign in with Google

Sign in with the Google account that owns (or can access) your shared photo folder.

3. Choose your folder

Paste your Google Drive folder link below, or just pick it directly from Drive.

Getting your Client ID & API key

  1. Go to console.cloud.google.com and create a new project.
  2. Open APIs & Services → Library, enable the Google Drive API and the Google Picker API.
  3. Open APIs & Services → OAuth consent screen. Choose External, fill in the basics, and under Test users add your own and your partner's Gmail address. Leave the app in Testing mode — that's what keeps it free and avoids Google's review process.
  4. Open APIs & Services → Credentials → Create credentials → OAuth client ID. Choose Web application, and under Authorized JavaScript origins add your GitHub Pages address (e.g. https://yourname.github.io). Copy the Client ID.
  5. Still in Credentials, choose Create credentials → API key. Click into it and restrict it to HTTP referrers (your GitHub Pages address) and to the Drive API + Picker API. Copy the key.
  6. Paste both values into this screen. Full details are in the README that came with this app.

About privacy

This app's code is hosted on GitHub Pages, which is public — anyone with the link can open the app itself.

What keeps your memories private is that the app only shows files it can access with your Google sign-in. Nobody can see your photos or videos unless they sign in with a Google account you've personally approved as a tester in your Google Cloud project, and that account can open the connected folder.

This app is not password-protected beyond Google sign-in. Don't rely on the website URL being secret.
